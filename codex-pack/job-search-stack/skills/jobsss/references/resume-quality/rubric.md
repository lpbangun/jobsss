# Resume quality reference v2

Presentation reference, not candidate evidence. A user master is optional.
Never copy sample achievements, identity, credentials or metrics into another
candidate's resume. Synthetic reference candidates are explicitly fictional.

Navy Professional: navy top rule/name, muted contact line, pale summary with
navy left edge, uppercase section headings/dividers, simple bullets, grouped
skills. Single column, Letter, safe margins, searchable text and readable type.

POC acceptance: one page; visible content uses 88–96% of printable height
(target 92%); body/bullet/skill type at least 9.5pt; no horizontal/vertical
overflow; no unexplained internal gaps above 36px; no literal Markdown links.
These are initial calibration values, not universal claims about hiring outcomes.
Sparse source evidence returns unresolved, rather than invented filler or giant
spacing. Restore omitted relevant supported facts before expanding spacing.

Independent review checks accuracy/ownership, relevant omissions, clarity,
balanced density and private-note leakage against source + job + rendered page.
Do not imply missing experience merely because the job requires it. A passed
machine review never records human approval or submission.
Missing required qualifications are fit gaps, not resume defects. Record them
separately; a truthful, well-presented resume can pass QA despite a fit gap.
Only misleading claims, omitted available evidence, or presentation defects
should block resume QA. Never repair a fit gap by inventing qualifications.

Sparse, typical and dense synthetic inputs are separate regression cases.
Readable sparse output may correctly fail the fill threshold. The fixture
expectation is honest diagnosis, not forcing every profile to pass.
